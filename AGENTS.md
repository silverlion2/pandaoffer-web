# PandaOffer Repository Instructions

- Follow `.website-sop.yml` and the global Website Development SOP for website changes.
- Preserve the Next.js App Router structure, JavaScript conventions, Tailwind utilities, and existing dependencies.
- Run the configured fast checks before handoff. Use a single Vitest worker on this Windows workspace when the default fork pool cannot start reliably.
- Do not require a paid service or a new external credential for the core university-matching journey.
- Keep admission and scholarship estimates clearly labeled as guidance rather than guarantees.
