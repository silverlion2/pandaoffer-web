# PandaOffer Web

A Next.js website for China study tours, campus visits, AI and healthcare industry routes, university matching, and Study in China guidance.
[Live site](https://pandaoffer-web.vercel.app)

## What This Project Covers

- China study tour marketing
- University matching and admissions guidance
- International student service pages

## Tech Stack

- Next.js
- React
- JavaScript
- Vercel
